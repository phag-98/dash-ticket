# 🎫 DashTicket

Dashboard de gerenciamento de tickets simples e funcional, feito com HTML, CSS e JavaScript puro — sem dependências.

## Funcionalidades

- **Dashboard** com contadores por status (Abertos, Em Andamento, Resolvidos)
- **Lista de tickets** com busca e filtros por status e prioridade
- **Criar tickets** com título, descrição, prioridade, categoria e responsável
- **Editar status** de qualquer ticket via modal
- **Excluir tickets**
- Dados persistidos no **localStorage** do navegador
- Tickets de demonstração incluídos na primeira abertura

## Como usar

Abra o arquivo `index.html` no navegador — não requer servidor ou instalação.

## Tecnologias

- HTML5
- CSS3 (variáveis CSS, grid, flexbox)
- JavaScript (ES6+, localStorage)
